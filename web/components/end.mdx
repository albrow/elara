### Продолжить обучение

В Elara используется язык программирования Rhai. Он отлично подходит для этой игры, но в реальных проектах применяется не так часто.
Если вы хотите развиваться дальше, рекомендуем изучать JavaScript или Python. Оба языка очень распространены и относительно просты для начала.
Синтаксис у них другой, но многие идеи, которые вы освоили в Elara (переменные, функции, циклы), пригодятся и там.

Удачи в вашем дальнейшем пути в программировании!

##### Изучайте JavaScript

JavaScript — один из самых популярных языков программирования. Изначально он создавался для разработки сайтов, но сегодня применяется во множестве областей.
Код на JavaScript во многом похож на Rhai, но есть и важные отличия.

- <a href="https://www.codecademy.com/learn/learn-javascript-fundamentals" target="_blank">Codecademy</a>
- <a href="https://www.khanacademy.org/computing/computer-programming/programming" target="_blank">Khan Academy</a>


##### Изучайте Python

Python — ещё один популярный язык, который легко начать учить. На нём можно делать почти всё: от автоматизации до машинного обучения и искусственного интеллекта.
Код на Python выглядит совсем иначе, чем на Rhai, но многие концепции остаются теми же.

- <a href="https://www.codecademy.com/catalog/language/python" target="_blank">Codecademy</a>
- <a href="https://www.codeforlife.education/play/#" target="_blank">Code for Life</a> (начинается с Blockly, затем переходит к Python)
