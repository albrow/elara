### Условные операторы

<Video youTubeId="hb0o3I5md7o" localVideoUrl={getLocalVideoUrl("if_statements")} />

«Условный оператор» (if) позволяет выполнять определённый код, если что-то
истинно. Вы можете использовать условный оператор для выполнения разных
действий в зависимости от разных условий. Если условие истинно, код
внутри фигурных скобок будет выполнен. С другой стороны, если условие
ложно, код внутри фигурных скобок выполняться не будет.

<Card type="try_it">В строке 1 попробуйте изменить значение `x` на что-то больше 10.</Card>

<RunnableExample
  code={`let x = 5;
if x < 10 {
  // Этот код выполнится только если x меньше 10.
  say("x меньше 10");
}`}
/>


Ниже приведён пример со строками. Запомните:

- Одинарный знак равенства (`=`) используется для присваивания значения переменной.
- Двойной знак равенства (`==`) используется для сравнения двух значений.

<Card type="try_it">В строке 1 измените переменную `fruit` на "апельсины" вместо "яблоки".</Card>

<RunnableExample
  code={`let fruit = "яблоки";

if fruit == "яблоки" {
  // Этот код выполнится только если fruit равно "яблоки".
  say("fruit равно 'яблоки'");
}

if fruit == "апельсины" {
  // Этот код выполнится только если fruit равно "апельсины".
  say("fruit равно 'апельсины'");
}
`}
/>
