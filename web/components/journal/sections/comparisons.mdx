### Сравнения

«Выражение сравнения» можно использовать для сравнения двух различных значений.
Например, выражение сравнения `1 < 2` даёт результат `true` (истина), потому что
1 меньше 2. Выражение сравнения `1 > 2` даёт результат `false` (ложь).

<Card type="tip">В примерах ниже удобно использовать кнопки «Шаг вперёд» и «Шаг назад», чтобы видеть каждое сравнение по очереди!</Card>

<RunnableExample
  code={`// Ровер скажет "true", потому что 1 меньше 2.
say(1 < 2);

// Ровер скажет "false", потому что 1 не больше 2.
say(1 > 2);`}
/>

#### Операторы сравнения

Вот полный список операторов сравнения и их значения:

| Оператор | Описание              | Пример    |
| -------- | --------------------- | --------- |
| `<`      | Меньше                | `1 < 2`   |
| `<=`     | Меньше или равно      | `2 <= 3`  |
| `>`      | Больше                | `3 > 4`   |
| `>=`     | Больше или равно      | `5 >= 6`  |
| `==`     | Равно                 | `7 == 8`  |
| `!=`     | Не равно              | `9 != 10` |

<Card type="tip">Одиночный знак равенства (`=`) используется для присваивания значения переменной. Если вы хотите проверить, равны ли два значения, не забудьте использовать два знака равенства (`==`).</Card>
