### Функции

<Video youTubeId="T8U2L4YVvUQ" localVideoUrl={getLocalVideoUrl("functions")}/>

Функции — это фундаментальный строительный блок программирования. Они
позволяют организовать код в небольшие фрагменты, которые можно
использовать повторно и комбинировать по-разному. Чтобы использовать
функцию, нужно её «вызвать».

Функции могут иметь входные данные (также называемые «аргументами»),
которые влияют на их поведение. Разные функции могут иметь разные типы
входных данных.

<Card type="tip">Все примеры кода здесь редактируемые! Вы можете изменить код и запустить его снова, чтобы увидеть результат.</Card>

Вот пример вызова функции `move_forward` с входным значением `4`:

<RunnableExample
  code={`move_forward(4);
`}
/>

Вот пример вызова функции `say` с входным значением `"Привет, мир!"`.

<RunnableExample
  code={`say("Привет, мир!");
`}
/>

Некоторые функции не требуют входных данных, но при их вызове всё равно
нужно включать круглые скобки. Вот пример вызова функции `turn_right`:

<RunnableExample
  code={`turn_right();
turn_right();
turn_right();
turn_right();
`}
/>
