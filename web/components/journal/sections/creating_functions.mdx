### Создание собственных функций

<Video youTubeId="KChh3VbnJFI" localVideoUrl={getLocalVideoUrl("creating_functions")} />

К этому моменту вы, вероятно, уже хорошо знакомы с использованием функций, но
вы также можете создавать свои собственные! Это мощная и важная часть программирования,
потому что она позволяет повторно использовать и адаптировать уже написанный код.

<Card type="tip">Только встроенные функции подсвечиваются фиолетовым цветом.</Card>

<Card type="tip">Если у функции нет входных параметров, всё равно нужно указывать пустые скобки.</Card>

Вот пример создания новой функции, которая не ожидает никаких входных параметров:

<RunnableExample
  code={`// Эта функция заставляет ровер сделать полный оборот
// (360 градусов).
fn do_a_360() {
  turn_left();
  turn_left();
  turn_left();
  turn_left();
}

do_a_360();
`}
/>

Вот пример функции под названием `greet`, у которой есть один входной параметр:
`name`. Функция заставит ровер произнести приветствие, используя любое
имя, переданное в качестве входного параметра.

<Card type="try_it">Попробуйте вызвать функцию `greet` со своим именем в качестве входного параметра.</Card>

<RunnableExample
  code={`// У этой функции один входной параметр: имя человека для
// приветствия.
fn greet(name) {
  say("Nice to meet you, " + name);
}

// Вызываем функцию greet с несколькими разными именами.
greet("Алиса");
greet("Борис");
greet("Вика");
`}
/>

Вам пока не обязательно это делать, но вы также можете создавать
функции, которые имеют выходное значение. Для этого используется ключевое слово `return`. Вот
пример функции под названием `add`, у которой два входных параметра: `a` и `b`. Функция
сложит два числа и вернёт результат.

<RunnableExample
  code={`fn add(a, b) {
  // Ключевое слово return заставляет функцию вывести (вернуть)
  // что-то. В данном случае мы возвращаем a + b.
  return a + b;
}

say(add(1, 2));
say(add(3, 4));
`}
/>
