### Переменные

<Video youTubeId="BBerbG81LrI" localVideoUrl={getLocalVideoUrl("variables")}/>

Переменные можно представить как «контейнеры», в которые можно
положить значения и использовать их позже. Почти всё можно хранить
в переменной: числа, строки или даже вывод функции.

Чтобы создать новую переменную, используйте ключевое слово `let`.
В примере ниже мы создаём новую переменную `x` и присваиваем ей значение `2`.

<Card type="try_it">Измените `2` на другое число и посмотрите, что произойдёт.</Card>

<RunnableExample
  code={`// Создаём новую переменную x и присваиваем ей значение 2.
let x = 2;

// Теперь мы можем использовать x как аргумент функции say.
say(x);

// Мы можем использовать x как число в математических операциях.
say(x + 1);
`}
/>

Переменная может хранить любой тип значения, включая строки. В примере ниже
мы создаём новую переменную `greeting` и присваиваем ей значение `"Привет"`.

<Card type="tip">Не используйте кавычки вокруг имени переменной.</Card>

<Card type="try_it">Измените `"Привет"` на другую строку.</Card>

<RunnableExample
  code={`// Создаём новую переменную greeting и присваиваем ей значение "Привет".
let greeting = "Привет";
say(greeting);
`}
/>

Если функция имеет вывод, можно сохранить его в переменной. Это очень полезно,
когда нужно сохранить вывод и использовать его позже.

<RunnableExample
  code={`// Сохраняем вывод функции read_data в переменную.
let data = read_data();

// Теперь мы можем использовать переменную позже в коде...
turn_right();
move_forward(1);
say(data);
`}
level={SANDBOX_WITH_DATA_POINT_LEVEL}
/>
