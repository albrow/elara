### Выходные значения функций

<Video youTubeId="O1XoNe0MfVg" localVideoUrl={getLocalVideoUrl("function_outputs")}/>

Некоторые функции могут иметь выходное значение, также называемое «возвращаемым значением». Если у
функции есть выходное значение, это означает, что она выдаёт результат при каждом
вызове, и вы можете использовать этот результат.

<Card type="tip">Не все функции имеют выходное значение. Например, функции `move_forward` и `turn_left` ничего не возвращают.</Card>

Давайте рассмотрим функцию `get_orientation`. Она возвращает строку
в зависимости от того, куда направлен ровер. Например, если ровер направлен
вправо, функция `get_orientation` вернёт `"right"`.

<Card type="try_it">Попробуйте добавить больше поворотов в код ниже и посмотрите, как изменится выходное значение функции `get_orientation`.</Card>

<RunnableExample
  code={`// Функция get_orientation возвращает направление, куда
// смотрит ровер.
say("I am facing " + get_orientation());

// Если мы повернём направо, выходное значение функции
// изменится.
turn_right();
say("Now I am facing " + get_orientation());
`}
/>

Следующий пример знакомит с «точками данных». Точки данных разбросаны по всей
Эларе и могут содержать различную информацию. Функция `read_data` возвращает данные,
хранящиеся в точке данных.

<Card type="warning">Функция `read_data` работает только если ровер находится рядом с точкой данных. Иначе произойдёт ошибка.</Card>

<RunnableExample
  code={`// Этот код использует *выходное значение* функции read_data как
// *входной параметр* функции say. Это заставит ровер произнести
// данные, хранящиеся в точке данных.
say(read_data());`}
  level={SANDBOX_WITH_DATA_POINT_LEVEL}
/>
