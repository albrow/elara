### Циклы While

<Video youTubeId="mCEAe5JF-vc" localVideoUrl={getLocalVideoUrl("while_loops")}/>

«Цикл while» — это что-то вроде комбинации условного оператора и цикла.

Цикл while похож на условный оператор, но имеет важные отличия:

1. Цикл while использует ключевое слово `while` вместо `if`.
2. В цикле while код внутри фигурных скобок будет **_повторяться_**, пока
    условие истинно. Тогда как в условном операторе код внутри фигурных
    скобок выполнится только **_один раз_**, если условие истинно.

Цикл while ниже использует условие `x < 5`, что означает, что он будет
выполняться, пока переменная `x` меньше 5. Поскольку мы увеличиваем
значение `x` на каждой итерации цикла, цикл выполнится 5 раз:

<RunnableExample
  code={`let x = 0;

while x < 5 {
  x = x + 1;
  say(x);
}`}
/>

Этот цикл while будет поворачивать ровер, пока он не будет смотреть влево.
Он работает с помощью условия `get_orientation() != "left"` (помните, символ
`!=` означает «не равно»). Как только ровер будет смотреть влево, условие
станет ложным, и цикл остановится.

<RunnableExample
  code={`while get_orientation() != "left" {
  turn_left();
}

say("Теперь я смотрю влево!");
`}
/>
